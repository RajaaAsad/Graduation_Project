# AI-Powered Website Builder

Our project, "AI-Powered Website Builder 🤖" 

is a chatbot specialized in creating frontend websites effortlessly. The idea behind it is to simplify website development for users by leveraging the power of AI. The chatbot guides users through a series of questions, understands their responses using NLP models, and then generates HTML, CSS, and JavaScript code.

Once the code is generated, Our Project automatically deploys the website, providing users with a ready-to-use link. Users can also make updates to the design and take the generated code for further customization.
